# How to play to Heroes of Might and Magic III in Filipino (Tagalog)

1. Buy _Heroes of Might and Magic III Complete Edition_ on GOG (not the HD version)
1. Install the game
1. Download VCMI (free)
1. Install VCMI
1. When installing VCMI, specify the location of the base game's `Data`, `MP3`, and `Maps` folders.
1. Set the language to _Filipino_
1. Install the _Pagsasalin sa Filipino_ mod
1. Launch the game

# Paano laruin ang Heroes of Might and Magic III sa Filipino (Tagalog)

1. Bumili ng _Heroes of Might and Magic III Complete Edition_ sa GOG (hindi ang HD na bersyon)
1. I-install ang laro
1. I-download ang VCMI (libre)
1. I-install ang VCMI
1. Kapag nag-i-install ng VCMI, tukuyin ang lokasyon ng mga folder na `Data`, `MP3`, at `Maps` ng base game.
1. Itakda ang wika sa _Filipino_
1. I-install ang _Pagsasalin sa Filipino_ mod
1. Ilunsad ang laro
